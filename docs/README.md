# docs

Architecture documentation, Architecture Decision Records (ADRs), and API reference.

Suggested structure:
- `architecture.md` — System diagram and component responsibilities
- `adr/` — One file per decision, named `001-use-bayesian-stats.md`, etc.
- `api.md` — OpenAPI summary / usage examples (auto-generated from FastAPI at `/docs`)
- `experiment-lifecycle.md` — State machine for experiment status transitions
